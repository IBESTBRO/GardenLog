# PWA Assets

Generated by PWA Icon Generator

## Contents

- `/icons/` - All PWA icons in various sizes
- `/splash/` - iOS splash screens (if generated)
- `manifest.json` - Web app manifest file
- `meta-tags.html` - HTML meta tags to include in your index.html
- `favicon.ico` - Favicon for your site (16x16, 32x32 and 48x48)
- `preview.html` - Open it in a browser to see the icons in use. Only for checking, not for your site

## Installation

The files are the same for every framework. Only the folder they go in and the place for the tags change.
Full steps with code: https://www.pwa-icon-generator.com/add-pwa-icons/

### Plain HTML

1. Copy `icons/`, `splash/`, `manifest.json` and `favicon.ico` into the folder that holds your `index.html`
2. Paste the contents of `meta-tags.html` into the `<head>` of every page

### React, Vue or Svelte with Vite (and Create React App)

1. Copy `icons/`, `splash/`, `manifest.json` and `favicon.ico` into `public/`
2. Paste the contents of `meta-tags.html` into the `<head>` of `index.html` (`public/index.html` in Create React App)
3. Do not import the icons from your components, or the build renames them and the manifest cannot find them
4. Using vite-plugin-pwa? Skip `manifest.json` and its link tag, and move its `icons` array into the plugin options

### Next.js

1. Copy `icons/`, `splash/` and `manifest.json` into `public/`
2. Put `favicon.ico` in `app/`, replacing the one already there, and keep no copy in `public/`
3. App Router: there is no `index.html`. Declare the manifest, icons and theme color with the `metadata` and `viewport` exports in `app/layout.tsx`
4. Pages Router: paste the tags into the `<Head>` of `pages/_document.tsx`, closing each one with `/>`

### Angular

1. Angular 17 or later: copy `icons/`, `splash/`, `manifest.json` and `favicon.ico` into `public/`. Older projects use `src/assets/` and list each file under `assets` in `angular.json`
2. Paste the contents of `meta-tags.html` into the `<head>` of `src/index.html`
3. Ran `ng add @angular/pwa`? Copy `icons/` over the placeholder icons, paste the contents of `manifest.json` into the existing `manifest.webmanifest`, and do not add a second manifest link
